# FirstCar backend (Supabase, EU)

Stateless edge functions plus four tables that hold no buyer data and only minimised seller text, as designed in `docs/architecture.md` §1.1, §5 and §8.
Income, savings, cases and evidence never reach this backend. Seller contact details are redacted on the device and again on the server, but redaction is heuristic (it misses street addresses, for example).

| Function | Caller | What it does |
|---|---|---|
| `extract-claims` | App (anonymous JWT) | Re-redacts the ad, checks the cache, calls `claude-haiku-5-5` with a JSON Schema, keeps only grounded claims, caches 30 d |
| `registry-check` | App (anonymous JWT) | Plate lookup through the registry adapter (`traficom-mock` for now). Nothing is stored |
| `if-handoff` | App (anonymous JWT), after consent | Validates the minimal payload against an allowlist, returns a one-time token (hash stored, 24 h) |
| `if-handoff-redeem` | If (`x-partner-secret` header) | Returns the payload for a token exactly once |

| Table | Contents | Kept for |
|---|---|---|
| `extraction_cache` | ExtractionV1 per (ad hash, schema version, model) | 30 days |
| `rate_limits` | Hit counts per hashed device id and globally | 24 hours |
| `funnel_counters` | Daily event counts, no ids (`funnel_kpis` shows only counts >= 10) | Aggregates |
| `handoff_tokens` | Token hash + consented payload | 24 hours |

RLS is on and `anon`/`authenticated` have no grants: only the functions (service role) can touch the data.
`purge_expired()` runs hourly through pg_cron.

## Local development

```bash
npm run functions:check   # copies packages/core into _shared/core, then type-checks every function
npm run functions:test    # handler tests + the migration run in PGlite, with coverage
```

`supabase/functions/_shared/core/` is generated by `scripts/sync-shared.mts` and gitignored. Run either script
(or `npm run sync:shared`) before serving or deploying functions.

Full local stack (needs Docker running): `npx supabase start`, then
`npx supabase functions serve --env-file supabase/functions/.env`.

## Deploying (not done yet)

1. Create the project in **eu-north-1 (Stockholm)** and enable anonymous sign-ins (Auth settings).
2. `npx supabase link --project-ref <ref>` and `npx supabase db push`.
3. Fill `supabase/functions/.env` from `.env.example`, then `npx supabase secrets set --env-file supabase/functions/.env`.
4. `npm run sync:shared && npx supabase functions deploy`.
5. Put the project URL and anon key into `apps/mobile/.env.local` (see `apps/mobile/.env.example`) and turn
   "Mock AI extraction" off in Settings. Without those values the app stays fully on-device.
