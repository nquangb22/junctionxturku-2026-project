# HeyMom ("Hei Äiti")

A quiet daily hello for a parent living alone. Junction hackathon, If P&C Insurance challenge.

The app notices silence: when a parent's normal daily activity (electricity pattern, kettle plug, an "I'm OK" button, or an automated call) doesn't show up, it gently checks with the parent first, then alerts family. An away mode watches the empty home during hard freezes.

- Architecture: [docs/architecture.md](docs/architecture.md)
- Stack: React Native (Expo) + Supabase (EU region)
- Status: design only, no code yet
